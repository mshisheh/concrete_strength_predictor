## Notes and Issues Encountered

### SHAP Installation Issue:
- SHAP package failed to install on Windows due to compilation requirements
- Error: Microsoft Visual C++ 14.0 or greater is required
- CUDA compilation errors with nvcc
- Solution: Removed SHAP from dependencies for now
- Alternative: Install Visual Studio Build Tools or use pre-compiled wheels

### Poetry Path Length Issue:
- Initial installation failed due to Windows path length limitations
- Solution: Configured shorter virtual environment paths
- Used: poetry config virtualenvs.path "C:\\venvs"

### Python Version Constraints:
- Specified Python version constraints to avoid compatibility issues
- Used: ">=3.9,<3.9.7 || >3.9.7,<4.0" to exclude problematic Python 3.9.7
